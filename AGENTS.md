# Rules for AI assistants in this repo

- Write in Simplified Technical English: short sentences, one instruction per sentence, simple words.
- This is a learning project. Let Rodrigo try first. Give a hint before you give code.
- Ask one question at a time.
- Functions marked `TODO (Rodrigo)` are his to write. Do not write them unless he asks.
- Every proof goes in `lean/` and must build with `lake build`.
- Add an entry to `docs/ai-usage-log.md` for each work session with an AI tool.
